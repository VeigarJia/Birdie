# 🏸 Birdie

**More play, less searching.**

A personal PWA that shows every UniMelb badminton court in one 30-minute time × court matrix. Tap a green cell to open the official PerfectMind booking page for that court and day.

Birdie only reads public availability. Login, booking and payment all happen on the official site.

## User guide

### Install on iPhone

1. Open the Birdie link in **Safari** (Chrome on iPhone can't add web apps to the Home Screen).
2. Tap **Share** (the square with an up arrow), then **Add to Home Screen** → **Add**.
3. Open Birdie from the 🏸 icon on your Home Screen.
4. Enter the **access key** you were given. You only do this once per device.

The Home Screen app and Safari keep separate storage. If you entered the key in Safari first, you'll be asked again in the Home Screen app.

On a computer, just open the link in any browser.

### Find a court

1. **Pick a date.** Birdie opens on today. Use **‹ ›** to step a day, or tap the date to choose from a calendar. You can look up to 14 days ahead, which is the official booking window.
2. **Pick a time range.** Choose a **Start time** and **End time** (30-minute steps). Birdie remembers your range for next time. The default is 16:00–18:00.
3. **Read the grid.** Each row is a 30-minute slot (for example, 17:00 means 17:00–17:30). Each column is a court (A–H).

| Cell | Meaning |
| --- | --- |
| 🟩 ✓ | Free. Tap to book |
| ▫️ – | Booked or closed |
| 🟨 ? | Couldn't be loaded. Not necessarily booked |
| Blank grey | Already passed (today only) |

The **Free** column shows how many courts are free in that slot. A `*` after the number means some courts couldn't be loaded, so the real number may be higher.

### Book

1. Tap a **green cell**. The official booking page for that court opens on the chosen day.
2. On the official page, pick your **duration** (30, 60, 90 or 120 minutes) and **start time**.
3. Log in with your UniMelb account if asked, then confirm and pay as usual.

You usually only need to log in the first time. After that, the official site remembers you.

Birdie never sees your UniMelb login or payment details.

### Keep it fresh

- The top right of the grid shows when the data was last updated (for example, **Updated 1 minute ago**).
- Tap **↻** (top right) to refresh at any time.
- After **2 minutes** the update time turns orange. You can still tap green cells.
- After **10 minutes** green cells fade and can't be tapped until you refresh. This prevents booking from badly outdated data.
- When you come back to Birdie from another app or from the booking page, it refreshes automatically if needed.

### FAQ

**A cell was green, but the official page says it's taken.**
Someone booked it in the meantime. The official site is always the final word. Go back to Birdie, refresh, and pick another slot.

**I'm asked for the access key again.**
The key was changed or cleared from this device. Enter the current key.

**"Unable to load availability".**
Birdie couldn't reach the official booking system. Check your connection and tap **Try again**. If it keeps failing, the official site may be down.

**"You're offline".**
Birdie needs the internet to load live availability. Booking links are paused until you're back online.

**Why can't I pick a date more than 14 days ahead?**
Courts can't be booked that far ahead on the official site yet.

## 使用指南（中文）

### 安装到 iPhone

1. 用 **Safari** 打开 Birdie 链接（iPhone 上的 Chrome 不能把网页添加到主屏幕）。
2. 点**分享**按钮（方框加向上箭头），选择**添加到主屏幕**，再点**添加**。
3. 从主屏幕上的 🏸 图标打开 Birdie。
4. 输入别人给你的**访问密钥**。每台设备只需输入一次。

主屏幕应用和 Safari 的存储是分开的。如果你先在 Safari 里输入过密钥，从主屏幕打开时还需要再输入一次。

在电脑上用任意浏览器直接打开链接即可。

### 查找空场

1. **选日期。** Birdie 默认打开当天。用 **‹ ›** 前后切换，或点日期从日历中选择。最多可查 14 天内的日期，与官方开放预订的范围一致。
2. **选时间段。** 选择**开始时间**和**结束时间**（以 30 分钟为单位）。Birdie 会记住你上次的选择，默认是 16:00–18:00。
3. **看表格。** 每一行是一个 30 分钟时段（例如 17:00 表示 17:00–17:30），每一列是一块场地（A–H）。

| 格子 | 含义 |
| --- | --- |
| 🟩 ✓ | 空闲，点击即可预订 |
| ▫️ – | 已被预订或未开放 |
| 🟨 ? | 未能加载，不代表已被预订 |
| 空白灰格 | 时间已过（仅当天） |

**Free** 列显示该时段有几块空场。数字后面带 `*` 表示部分场地未能加载，实际空场可能更多。

### 预订

1. 点击一个**绿格**，会打开该场地在所选日期的官方预订页面。
2. 在官方页面上选择**时长**（30、60、90 或 120 分钟）和**开始时间**。
3. 如有提示，用墨大账号登录，然后照常确认并付款。

一般只有第一次需要登录，之后官方网站会记住你。

Birdie 不会接触你的墨大账号或支付信息。

### 保持数据最新

- 表格右上方显示数据的更新时间（例如 **Updated 1 minute ago**）。
- 随时可以点右上角的 **↻** 刷新。
- 超过 **2 分钟**，更新时间会变成橙色，绿格仍然可以点。
- 超过 **10 分钟**，绿格会变淡，刷新之前不能点。这是为了避免根据过时太久的数据去预订。
- 从其他 App 或预订页面回到 Birdie 时，如有需要会自动刷新。

### 常见问题

**格子是绿的，点进官方页面却显示已被订。**
在这期间有人先订了。一切以官方网站为准。回到 Birdie 刷新一下，换个时段即可。

**又要求我输入访问密钥。**
密钥已更换，或这台设备上的密钥被清除了。输入当前的密钥即可。

**显示 "Unable to load availability"。**
Birdie 连不上官方预订系统。检查网络后点 **Try again**。如果一直失败，可能是官方网站暂时出了问题。

**显示 "You're offline"。**
Birdie 需要联网才能获取实时空场信息。恢复联网之前，预订链接会暂停使用。

**为什么不能选 14 天以后的日期？**
官方网站目前还不能预订那么远的日期。

## Deploy (Vercel)

1. Import the GitHub repo into Vercel.
2. Set the `BIRDIE_ACCESS_KEYS` environment variable (see below).
3. Deploy. `vercel.json` pins Functions to `syd1` (Sydney).
4. On iPhone, open the URL in Safari → Share → **Add to Home Screen**, then enter the key once.

## Access keys

Every API request needs a key. Each person or group gets their own, so one can be revoked without affecting the others.

**Where they live**

| Place | What |
| --- | --- |
| Vercel → Project → Settings → Environment Variables | `BIRDIE_ACCESS_KEYS`: the source of truth, as `name:key,name:key` |
| Vercel (same page) | `BIRDIE_ACCESS_KEY`: optional legacy single key, logged as `owner` |
| Each user's device | The key they typed, in that browser's LocalStorage |
| `.env.local` (your machine, git-ignored) | Keys for local development only |

**Add a key**

1. Run `npm run key -- alice`. It prints a key for Alice and the entry `alice:<key>`.
2. In Vercel, edit `BIRDIE_ACCESS_KEYS` and append `,alice:<key>` (comma-separated, no spaces needed).
3. **Redeploy** (Deployments → ⋯ → Redeploy). Env changes only apply to new deployments.
4. Send Alice the key.

Names may use letters, digits, `-` and `_`. Keys must be at least 16 characters; the generator makes 43-character URL-safe keys with no `:` or `,`.

**See existing keys**

In Vercel, open Settings → Environment Variables and click the eye icon on `BIRDIE_ACCESS_KEYS`. Birdie itself never displays or logs key values.

**See who is using Birdie**

Vercel → Project → Logs. Each request logs the key's name, e.g. `[birdie] request key=alice date=2026-11-25`.

**Revoke a key**

1. In Vercel, edit `BIRDIE_ACCESS_KEYS` and delete that person's `name:key` entry.
2. Redeploy.

Their next request gets `401`, the app clears the stored key and asks for a new one. Everyone else keeps working.

## How it works

```text
iPhone PWA ──(Bearer key)──> /api/availability?date=YYYY-MM-DD ──> PerfectMind (anonymous session)
     └── tap green cell ──────────────────────────────────────────> official booking page
```

- `lib/perfectmind/`: anonymous session (cookies + anti-forgery token), facility list, availability, parsing, booking links
- `lib/matrix.ts`: cell status, Past, Free counts, freshness
- `app/api/availability/route.ts`: the only API; access-key protected, 30 s cache, request coalescing
